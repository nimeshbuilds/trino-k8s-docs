# Error codes from source

Every engine error code in `io.trino.spi.StandardErrorCode` of Trino 484: 188 codes.

A failed query reports an error name, a numeric code and an error type. They are visible in the client error, the Web UI, `system.runtime.queries` (`error_type`, `error_code`) and query completed events.

Connectors add their own codes on top of these, for example `HIVE_METASTORE_ERROR` or `ICEBERG_INVALID_METADATA`. Those are defined in each plugin and are not listed here.
