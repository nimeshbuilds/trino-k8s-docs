# Configuration properties from source

Every configuration property declared with `@Config` in the main Java sources of Trino release 484: 1402 properties in 208 classes across 59 modules.

These pages are generated from the source code, so they include properties that the official documentation does not mention.

## How to read these pages

- **Property** is the key you write in a properties file.
- **Type** is the Java type of the setter parameter. `DataSize` takes values like `512MB` or `2GB`. `Duration` takes values like `30s`, `5m` or `1h`.
- **Default in source** is the Java expression that initialises the field. An empty cell means there is no initialiser, so the property is unset or the default is computed elsewhere. Some defaults are computed from the machine, for example from the JVM heap size.
- **Legacy names** are older keys that still work.
- `sensitive` marks values that Trino redacts. `hidden` and `deprecated` come from the matching annotations.
- **Removed properties** are rejected at startup.
- A class marked "Bound with prefix" is registered under that prefix in at least one place. Check the official documentation for the full key.

## Which file does a property go in?

| Module | Usually set in |
|---|---|
| `core/trino-main`, `core/trino-server*` | `etc/config.properties` |
| `plugin/<connector>` | `etc/catalog/<catalog>.properties` |
| `lib/trino-filesystem-*`, `lib/trino-metastore`, `lib/trino-hive-formats`, `lib/trino-parquet`, `lib/trino-orc` | The catalog file of a connector that uses the library, for example Hive, Iceberg or Delta Lake |
| `plugin/trino-exchange-*` | `etc/exchange-manager.properties` |
| `plugin/trino-resource-group-managers` | `etc/resource-groups.properties` |
| `plugin/trino-session-property-managers` | `etc/session-property-config.properties` |
| `plugin/trino-password-authenticators` | `etc/password-authenticator.properties` |
| Event listener plugins | `etc/event-listener.properties` or the files named in `event-listener.config-files` |
| Access control plugins such as `plugin/trino-opa`, `plugin/trino-ranger` | `etc/access-control.properties` |

This table is a guide. The official documentation for each feature is the authority on where a key belongs.

## Not covered here

- Properties defined in the Airlift libraries that Trino builds on, for example `http-server.http.*`, `http-server.https.*`, `http-server.log.*`, `http-server.process-forwarded`, `node.*`, `discovery.*`, `log.*`, `openmetrics.*`, `tracing.*`, `otel.*` and most `http-client.*` keys. The ones Trino documents are in the upstream administration pages and are indexed in [documented-properties.md](../documented-properties.md).
- Selector properties that pick a plugin by name, such as `connector.name`, `access-control.name`, `event-listener.name`, `exchange-manager.name` and `cache-manager.name`. See [plugins-and-connectors.md](../plugins-and-connectors.md).
- Table, schema, column and analyze properties. See each connector page.
- JVM options, which go in `etc/jvm.config`.
